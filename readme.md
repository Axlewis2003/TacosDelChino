📄 Receipts
Receipts are automatically saved to the receipts/ folder when an order is confirmed. Each file is named by date and time:
receipts/20260521-153045.txt

📋 Classes Overview

Main.java — controls all screens and user input
Taco.java — stores taco choices and calculates taco price
Order.java — holds all items and calculates the order total
Drink.java — stores drink size and returns its price
ChipsAndSalsa.java — stores salsa type, always $1.50


⚠️ Rules

If you order 0 tacos, you must add at least a drink or chips & salsa
Only one chips & salsa per order
Regular toppings (lettuce, cilantro, onions, etc.) are free
Meat and cheese are always premium (added cost)
